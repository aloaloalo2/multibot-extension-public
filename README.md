# Multi Bot для Chrome

Розширення для роботи з відео, YouTube, Google Flow та Classroom.

## Встановлення на Mac

Попросіть Codex на своєму Mac встановити розширення за посиланням на цей репозиторій. Codex завантажить файли в папку `~/flow-bot/heygen-grabber` і допоможе додати її в Chrome.

Якщо розширення вже встановлене, спершу визначте його поточну папку в `chrome://extensions`. Збережіть наявні особисті файли й налаштування. Перед заміною або об'єднанням файлів перевірте локальні зміни та переконайтеся, що вони не будуть втрачені.

Для нового встановлення:

1. Завантажте репозиторій у `~/flow-bot/heygen-grabber` за допомогою Git.
2. Відкрийте `chrome://extensions` і ввімкніть режим розробника.
3. Натисніть «Завантажити розпаковане розширення» та виберіть папку `heygen-grabber`.

## Оновлення

Попросіть Codex оновити Multi Bot за посиланням на цей репозиторій. Codex перевірить папку встановленого розширення та її локальні зміни, отримає нову версію Git і після цього допоможе перезавантажити розширення на сторінці `chrome://extensions`.

Особистий файл `job.txt`, локальні резервні копії та налаштування браузера залишаються на комп'ютері. Якщо є незбережені зміни коду або конфлікт файлів, спочатку збережіть їх і з'ясуйте, як їх поєднати.
